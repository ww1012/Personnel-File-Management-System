# 人事管理系统

用于维护员工档案、部门、岗位、人事变动和职员账号。

## 功能与权限

| 角色 | 可用功能 |
| --- | --- |
| 管理员 | 工作台统计；员工新增、查询、编辑、调岗、离职；部门和岗位维护；人事变动查询；职员账号创建、停用、重置密码。 |
| 职员 | 查看自己的档案；仅修改手机号、邮箱、联系地址、学历；修改本人密码和退出。 |

后端按登录账号判定角色。职员不能读取其他员工，也不能调用管理员接口；退出、停用或密码变更后旧会话会失效。

## 环境要求

- Node.js 22+，npm 10+
- Java 21+，Maven 3.9+
- MySQL

## 从头启动

终端一：

```bash
cd backend
mvn spring-boot:run
```

终端二：

```bash
cd frontend
npm install
npm run dev
```
