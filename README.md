# 人事管理系统

软件工程实训课程项目，用于维护员工档案、部门、岗位、人事变动和职员账号。当前版本使用虚构演示数据和后端内存存储；MySQL 尚未接入。

## 功能与权限

| 角色 | 可用功能 |
| --- | --- |
| 管理员 | 工作台统计；员工新增、查询、编辑、调岗、离职；部门和岗位维护；人事变动查询；职员账号创建、停用、重置密码。 |
| 职员 | 查看自己的档案；仅修改手机号、邮箱、联系地址、学历；修改本人密码和退出。 |

后端按登录账号判定角色。职员不能读取其他员工，也不能调用管理员接口；退出、停用或密码变更后旧会话会失效。

## 环境要求

- Node.js 22+，npm 10+
- Java 21+，Maven 3.9+
- 当前不需要 MySQL

## 从头启动

终端一：

```bash
cd backend
mvn spring-boot:run
```

终端二：

```bash
cd frontend
npm install
npm run dev
```

访问前端 <http://127.0.0.1:5173/>，后端健康检查为 <http://127.0.0.1:8080/api/health>。

## 常见启动问题

| 现象 | 处理方式 |
| --- | --- |
| `java` 或 `mvn` 找不到 | 安装 Java 21+ 和 Maven，重新打开终端后执行 `java -version`、`mvn -version`。 |
| 前端无法登录 | 确认后端终端仍在运行，且健康检查返回 `status: UP`。 |
| 5173 或 8080 端口被占用 | 关闭占用端口的旧开发进程，再重新启动。 |
| 页面打开的是本地 `index.html` | 使用 Vite 地址，不要直接双击 HTML 文件。 |

## 存储限制与交接

默认开发模式不读取数据库配置，服务重启后恢复初始演示数据；浏览器刷新不会清除正在运行的后端内存数据。MySQL 接入说明、兼容要求和验收清单见 [数据库接入交接](docs/数据库接入交接.md)。
