# 人事管理系统接口文档

基础地址：`/api`。除登录和健康检查外，接口使用 `Authorization: Bearer <token>`。

| 模块 | 方法与路径 | 权限 | 说明 |
| --- | --- | --- | --- |
| 健康 | `GET /health` | 公开 | 返回服务状态。 |
| 认证 | `POST /auth/login`、`POST /auth/logout`、`GET /auth/me`、`PUT /auth/password` | 登录按接口要求 | 登录、退出、当前用户、修改本人密码。 |
| 工作台 | `GET /dashboard` | ADMIN | 实际计算统计、部门分布、近期变动。 |
| 员工 | `GET/POST /employees`、`GET/PUT /employees/{id}` | ADMIN | 查询、分页、新增、详情、普通编辑；普通编辑不修改部门、岗位、状态。 |
| 人事变动 | `POST /employees/{id}/transfer`、`POST /employees/{id}/resign`、`GET /changes` | ADMIN | 调岗、离职和变动历史。 |
| 部门 | `GET/POST /departments`、`PUT/DELETE /departments/{id}` | ADMIN | 被员工或历史记录引用时删除返回 409。 |
| 岗位 | `GET/POST /positions`、`PUT/DELETE /positions/{id}` | ADMIN | 被员工或历史记录引用时删除返回 409。 |
| 职员账号 | `GET/POST /accounts`、`POST /accounts/{username}/disable`、`POST /accounts/{username}/reset-password` | ADMIN | 创建、停用、重置职员账号。 |
| 我的资料 | `GET /profile`、`PUT /profile` | EMPLOYEE | 后端按令牌绑定员工；只接受手机号、邮箱、地址、学历。 |

常见状态码：未登录或会话失效为 401，越权为 403，字段或关联无效为 400，唯一约束或引用删除冲突为 409。
