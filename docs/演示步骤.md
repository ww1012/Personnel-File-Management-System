# 约 5 分钟演示步骤

1. 打开登录页，使用 `admin / Admin@123` 登录，说明后端按账号决定角色。
2. 展示工作台：员工总数、在职/离职人数、部门分布、近期变动均来自后端。
3. 进入员工管理，演示关键词搜索、部门/状态筛选、详情抽屉和分页。
4. 新增一个部门和岗位，再新增员工；展示员工详情与入职记录。
5. 为新员工创建职员账号；演示调岗，进入人事变动查看前后信息。
6. 演示离职确认提示，说明档案保留、变动记录写入、关联账号停用。
7. 退出后以 `zhangmin / Employee@123` 登录，展示“我的资料”只包含本人资料和允许编辑的联系字段。
8. 展示修改密码入口和直接访问管理员路由被限制的效果。
